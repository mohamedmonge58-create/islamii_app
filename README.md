🚀 Getting Started
Prerequisites
- Flutter SDK
- Dart SDK
Installation
1. Clone the repository:
   git clone https://github.com/mohamedmonge58-create/islamii_app.git
2. Navigate to the project directory:
   cd islamii_app
3. Install dependencies:
   flutter pub get
4. Run the app:
   flutter run
